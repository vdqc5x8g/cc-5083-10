焦点融合图像恢复台

载入同一场景、不同焦点位置的多张照片，工具会估计每处清晰度、生成保留遮挡边缘的选择权重、重建像素，并把全部输入都模糊的区域标记为不可靠。

图形入口即本页面；命令行 node bin/focus-fusion.js 仅作辅助。
